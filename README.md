2. GA

The GA intelligent algorithm is a simple implementation that tries to find a collection of characters. 
It is implemented using the crossover algorithm in addition to mutation.

The GA implementation used both Oracle-Guided search as well as Black-Box Searches
With Oracle-Guided search leading to very fast convergence
